♨ PLANCHER — Plancher chauffant PID

♨
PLANCHER
Régulation PID ambiante · V3V motorisée · Circulateur · 3 niveaux de sécurité

Principe général

Le bloc PLANCHER régule la température ambiante d'une pièce via un PID. Il commande une vanne 3 voies motorisée (deux sorties indépendantes : ouvre / ferme) et un circulateur. Les deux impulsions V3V ne sont jamais actives simultanément.

Algorithme PID — détail cycle par cycle

À chaque cycle de scan (dt_ms millisecondes), le moteur exécute :

# 1. Lire la consigne : port SP câblé OU valeur fixe dans les paramètres
sp = read_analog(sp_ref) if sp_ref else sp_fixed

# 2. Calculer l'erreur et vérifier la bande morte
error  = sp - t_amb          # positif = trop froid, négatif = trop chaud
active = error > dead_band   # dead_band défaut = 0.5°C

# 3. PID uniquement si actif (erreur > bande morte)
if active:
    integral += ki * error * (dt_ms / 1000.0)     # intégrale bornée [-100..100]
    derivative = kd * (error - prev_err) / dt_s   # dérivée sur la variation
    pid_out = kp*error + integral + derivative     # sortie [0..100%]
else:
    pid_out = 0.0
    integral = max(0.0, integral)   # évite l'intégrale négative

# 4. Commandes sorties
V3V_OUV = active     # impulsion ouverture si chauffe nécessaire
V3V_FER = not active # impulsion fermeture si température OK
CIRC    = active     # circulateur ON uniquement si chauffe active
💡 Le pourcentage PID (RF_out) est enregistré dans un registre RF pour diagnostic mais ne pilote pas directement la vanne — la V3V est tout/rien par impulsions. Le PID sert à activer/désactiver le circuit, pas à moduler.

Sécurités — 3 niveaux prioritaires

Les sécurités sont évaluées avant le PID. Dès qu'une condition est vraie, le PID ne s'exécute pas.

PrioritéConditionV3V OuvreV3V FermeCirculateurRaison
1 — GELT_amb < min_temp (défaut 5°C)ONOFFONFaire circuler l'eau chaude pour protéger le plancher du gel
2 — SURCHAUFFET_amb > max_temp (défaut 35°C)OFFONOFFFermer la V3V et couper le circulateur
3 — DÉPARTT_départ > max_depart (défaut 45°C)OFFONONEau trop chaude : fermer la V3V mais garder le circulateur pour refroidir le plancher
⚠ La sécurité départ n'est active que si la sonde départ est câblée. Sans cette sonde, seul le PID commande la V3V.

Logique complète simplifiée

EN = False ? → Tout OFF
T_amb < 5°C ? → PROTECTION GEL : V3V ouverte + CIRC ON
T_amb > 35°C ? → SURCHAUFFE : V3V fermée + CIRC OFF
T_départ > 45°C ? → ALM DÉPART : V3V fermée + CIRC ON (refroidissement)
PID : erreur > 0.5°C ? → ACTIF : V3V_OUV + CIRC ON
PID : erreur ≤ 0.5°C ? → INACTIF : V3V_FER + CIRC OFF

Paramètres configurables

🔥 CHAUDIERE — Régulation avec anti-cyclage

🔥
CHAUDIERE
Tout/rien hystérésis sur T départ · Anti-cyclage min_on/min_off · Sécurité départ

Logique de régulation

La chaudière est régulée en tout/rien avec hystérésis sur la température de départ (pas le retour). La chaudière granulés ne peut pas s'allumer et s'éteindre rapidement — l'anti-cyclage impose des durées minimales.

# État courant et timer (persistant entre cycles)
st = {"on": False, "timer": 0.0}   # initialisé au premier cycle
st["timer"] += dt_ms              # incrémenté à chaque cycle

# Sécurité max départ (prioritaire)
if t_dep >= max_dep:              # défaut 90°C
    brulee = False; pompe = True  # brûleur OFF, pompe reste ON

# Extinction : T_départ atteint SP + hystérésis ET durée min ON écoulée
if st["on"] and t_dep >= sp+hyst and st["timer"] >= min_on:
    st["on"] = False; st["timer"] = 0.0

# Allumage : T_départ descend sous SP - hystérésis ET durée min OFF écoulée
if not st["on"] and t_dep < sp-hyst and st["timer"] >= min_off:
    st["on"] = True; st["timer"] = 0.0

# Les deux sorties suivent le même état
BRULEE = st["on"]
POMPE  = st["on"]

Anti-cyclage — pourquoi c'est critique

🔥 Une chaudière à granulés ne peut pas être allumée et éteinte librement. La procédure d'allumage dure plusieurs minutes et une extinction prématurée laisse du combustible non brûlé dans le foyer.
ParamètreDéfautRôle
min_on_s60 sDurée minimale de fonctionnement avant autorisation d'extinction
min_off_s30 sDurée minimale d'arrêt avant autorisation de rallumage
hysteresis3°CÉcart entre seuil allumage (SP−hyst) et extinction (SP+hyst)
T_départ ≥ 90°C ? → ALM DÉPART : brûleur OFF, pompe ON
Chaudière ON et T_départ ≥ SP+hyst (68°C) et timer ≥ min_on ? → Extinction autorisée
Chaudière OFF et T_départ < SP−hyst (62°C) et timer ≥ min_off ? → Allumage autorisé

Rehausse chaudière — comment ça marche

Il n'y a pas de "rehausse automatique" câblée en dur dans le bloc CHAUDIERE lui-même. La rehausse se fait par le câblage FBD entre les blocs :

📐 Principe : Le bloc PLANCHER écrit sa sortie PID dans un registre RF (ex. RF2). Un bloc COMPARE_F compare ce registre à un seuil (ex. 30%). Si la demande est suffisante, il active une sortie booléenne qui déclenche la chaudière via un port EN du bloc CHAUDIERE.

Exemple de câblage type pour la rehausse :

# Dans le FBD :
PLANCHER.reg_out  →  RF2             # PID plancher en % → registre RF2
RF2 → COMPARE_F.IN  (seuil = 20%)   # si plancher demande > 20%
COMPARE_F.GT → CHAUDIERE.EN        # → autoriser la chaudière

# Ou plus simplement : relier la DV de l'interrupteur "mode CHAUFFE"
# au port EN de la chaudière — la chaudière ne tourne que si le mode est actif
DV(marche_chauffe) → CHAUDIERE.EN
✅ Le bloc CHAUDIERE ignore le port EN si non câblé (défaut = toujours actif). Pour conditionner la chaudière à la demande du plancher, câbler la sortie active du plancher (via une DV ou un bit mémoire) sur le port EN de la chaudière.

☀ SOLAR — Solaire thermique ΔT + vanne directionnelle

☀
SOLAR
Hystérésis ΔT · Priorité ECS → Chauffage · Pompe TOR ou 0-10V · Anti-gel capteur

Gestion du ΔT et hystérésis pompe

delta = T_capteur - T_ballon_ECS

# Démarrage pompe si ΔT ≥ delta_on (défaut 8°C)
if not pompe_on and delta >= delta_on:  pompe_on = True
# Arrêt pompe si ΔT < delta_off (défaut 3°C)
if pompe_on and delta < delta_off:      pompe_on = False

Cette hystérésis (8°C pour démarrer, 3°C pour arrêter) évite le pompage intempestif quand le soleil se couvre brièvement.

Priorité ECS → Chauffage

Pompe ON ?
├─ ECS < 60°C ? → Vanne ECS ON Vanne Chauf OFF (priorité ECS)
├─ ECS OK et chauff < 50°C ? → Vanne ECS OFF Vanne Chauf ON
└─ Tout OK ? → Pompe OFF (pas besoin de chauffe)

Pompe proportionnelle 0-10V (optionnel)

Si le mode pump_mode = "analog_0_10" est sélectionné, la vitesse de pompe est proportionnelle au ΔT :

# Plus le ΔT est grand, plus la pompe tourne vite
pct = pump_min_pct + (delta - delta_on) / (delta_max - delta_on) * (100 - pump_min_pct)
volts = pct / 10.0   # converti en 0-10V pour la sortie AV

Anti-gel capteur

Mode antigelComportement
offT_capteur < 5°C → tout OFF (risque de gel assumé)
ecsSi T_ballon > temp_source → ouvre vanne chauf + pompe pour réchauffer les capteurs avec l'eau du ballon
chaudiereMême principe mais depuis la sonde départ chaudière
⚠ Si T_capteur ≥ 120°C (stagnation) → pompe et vannes coupées immédiatement, quelle que soit la situation.

🏠 ZONE_CHAUF — Zone de chauffage vanne motorisée

🏠
ZONE_CHAUF
Tout/rien hystérésis · Délais ouverture/fermeture moteur · Une sortie vanne
# Même logique d'hystérésis que la chaudière, mais sur T_ambiante
currently_open = vanne_ouverte

# Fermeture : T ≥ SP + hyst ET durée min ouverte écoulée
if open and T >= sp+hyst and timer >= delay_open:
    open = False; timer = 0

# Ouverture : T < SP - hyst ET durée min fermée écoulée
if not open and T < sp-hyst and timer >= delay_close:
    open = True; timer = 0

VANNE = open

Les délais delay_open_s et delay_close_s (défaut 120s chacun) protègent le moteur de la vanne contre les inversions trop rapides.

🚿 ECS_BLOC — Eau Chaude Sanitaire + anti-légionellose

🚿
ECS_BLOC
Régulation ballon · Condition primaire plus chaud · Anti-légionellose hebdomadaire automatique
# La pompe ne démarre QUE si deux conditions sont réunies :
need_heat = T_ecs < sp - hyst     # 1. ballon a besoin de chaleur
prim_ok   = T_prim > T_ecs + 3°C # 2. source primaire est plus chaude de 3°C
pump_on   = need_heat and prim_ok

# Hystérésis sur la pompe (évite les cycles rapides)
if pompe_on and T_ecs >= sp + hyst:  pompe = False
if not pompe_on and pump_on:         pompe = True

Anti-légionellose automatique

# Chaque semaine, à un jour/heure configuré, monter à 65°C
antileg_active = (now.weekday() == al_day) and (now.hour == al_hour)
sp = sp_antileg (65°C) if antileg_active else sp_ecs (55°C)
ParamètreDéfautDescription
sp_ecs55°CConsigne normale du ballon ECS
sp_antileg65°CConsigne montée anti-légionellose
antileg_day0 (Lundi)Jour de la semaine (0=Lun … 6=Dim)
antileg_hour3hHeure de déclenchement (3h = nuit creuse)
hysteresis2°CBande morte sur la pompe
ℹ Le traitement anti-légionellose dure jusqu'à ce que T_ballon atteigne 65°C + hystérésis. Si la source primaire n'est pas assez chaude (chaudière éteinte), le traitement est différé.

📅 PROG_H — Programmation horaire Jour/Nuit

📅
PROG_H
Consigne dynamique JOUR/NUIT/VACANCES · Planning hebdo par jour · Sortie registre RF
# Chaque cycle, le bloc lit l'heure système et décide le mode
now_min = now.hour * 60 + now.minute

# Est-ce dans la plage jour ? (gère l'enjambement minuit)
is_jour = h_debut*60+m_debut <= now_min < h_fin*60+m_fin

# Sélection de la consigne active
if   vacances:  sp = sp_vac  (ex: 15°C)
elif jour:      sp = sp_jour (ex: 20°C)
else:           sp = sp_nuit (ex: 17°C)

# Écriture dans un registre → câblé sur le port SP du PLANCHER
RF5 = sp   # le PLANCHER lit RF5 comme consigne dynamique

Le mode hebdomadaire permet une consigne différente par jour de la semaine. Par exemple : confort du lundi au vendredi, réduit le week-end.

Câblage type — Chaudière + Plancher chauffant

─── Programme FBD complet ───────────────────────────────────────────────────

PROG_H                          # programmation horaire → RF5 (consigne)
  └─ reg_sp ──────────────────────────────────────────────► RF5

  ├─ pv_ref_amb = ANA0          # T ambiante → sonde NTC salon
  ├─ pv_ref_depart = ANA1       # T départ eau chaude
  ├─ pv_ref_retour = ANA2       # T retour plancher
  ├─ sp_ref = RF5               # consigne depuis PROG_H
  ├─ out_v3v_ouv → K7           # impulsion ouverture vanne
  ├─ out_v3v_fer → K8           # impulsion fermeture vanne
  ├─ out_circ    → K9           # circulateur plancher
  └─ reg_out ─────────────────────────────────────────────► RF2 (PID %)

COMPARE_F                       # demande chaudière si PID > 20%
  ├─ IN = RF2
  ├─ threshold = 20.0
  └─ GT ──────────────────────────────────────────────────► M0 (rehausse)

CHAUDIERE                       # brûleur granulés
  ├─ pv_ref_depart = ANA3       # T départ chaudière
  ├─ pv_ref_retour = ANA4
  ├─ sp = 65°C, hyst = 3°C
  ├─ min_on_s = 120, min_off_s = 60
  ├─ EN = M0                    # ← rehausse depuis PLANCHER
  ├─ out_brulee → K3            # brûleur
  └─ out_pompe  → K4            # pompe chaudière

SOLAR
  ├─ pv_ref_capteur = ANA5     # T capteur solaire
  ├─ pv_ref_ecs = ANA6         # T ballon ECS
  ├─ pv_ref_chauf = ANA1       # T ballon chauffage (partagé avec PLANCHER)
  ├─ delta_on = 8°C            # ΔT démarrage pompe

  ├─ sp_ecs = 55°C
  ├─ antileg_day = 0 (Lundi)   # traitement anti-légionellose le lundi à 3h

Interactions entre blocs — flux de données

Les blocs métier ne se "parlent" pas directement. Ils communiquent uniquement via les registres RF et les bits mémoire M, câblés dans le FBD par l'utilisateur.

PROG_H → RF5 (consigne) → PLANCHER.sp_ref
PLANCHER → RF2 (PID%) → COMPARE_F → M0 (demande chauffe) → CHAUDIERE.EN
SOLAR → K1 (pompe), K2 (vanne ECS), K3 (vanne chauf) → GPIO physiques
ECS_BLOC ← ANA3 (T chaudière primaire) ← physique
✅ Ce découplage par registres RF permet de modifier facilement la logique sans toucher aux blocs métier : changer un seuil dans COMPARE_F suffit pour ajuster quand la chaudière se rehausse.
