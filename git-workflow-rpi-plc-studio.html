2

Ajouter les fichiers modifiés

terminal 
# Tout ajouter d'un coup (recommandé si .gitignore est bien configuré)
$ git add .

# Ou fichier par fichier :
$ git add block_editor.py plc_engine.py chaudiere_Maison.plcproj
⚠

Ne jamais faire git add . sans avoir un .gitignore en place (voir section 6). C'est l'absence de ce fichier qui a causé les conflits de cache système.

3

Créer un commit

terminal 
$ git commit -m "P9_CH: ajout garde v3v_sol sur SR sr_s8 et sr_s10"

Bonnes pratiques pour le message :

· Court et précis : ce qui change, pas comment
· Commence par le bloc ou fichier concerné si pertinent
· Exemples : "P8_LOI: correction logique jour/nuit", "synoptic: ajout widget K2 V3V"

Résoudre des conflits lors du pull — rebase

si git pull échoue
ℹ

Cas rencontré : GitHub avait un commit que ton PC n'avait pas. Le rebase a échoué sur des fichiers cache système (mesa_shader_cache, icon-cache.kcache…) qui n'auraient jamais dû être commités.

A

Récupérer les mises à jour depuis GitHub

terminal 
$ git pull --rebase origin main
CONFLIT (renommage/suppression) : ...mesa_shader_cache...
error: impossible d'appliquer 3ad9f3f...
B

Supprimer tous les fichiers en conflit

terminal 
# Supprimer en masse tous les fichiers marqués "supprimé chez nous"
$ git status --short | grep "^DU " | awk '{print $2}' | xargs git rm -f --
rm 'sortie_GPIO/$~/.cache/icon-cache.kcache'
rm 'sortie_GPIO/$~/.cache/mesa_shader_cache/...'
...
C

Continuer le rebase puis pousser

terminal 
$ git rebase --continue
(un éditeur s'ouvre pour valider le message — sauvegarder et fermer)
Rebase appliqué avec succès.

$ git push origin main
To github.com:vinc38300/rpi-plc-studio.git
   6194d12..a7c2f1e  main -> main
✕

Si tu veux tout annuler et revenir à l'état avant le pull :
git rebase --abort

6

Configurer .gitignore — éviter que ça se reproduise

à faire une fois

Ces fichiers ont été accidentellement inclus dans le repo lors d'un git add . qui a capturé le dossier home $~. Le .gitignore les exclura désormais.

MotifCe que ça exclut
$~Dossier home mal capturé ($~ au lieu de ~)
.cache/Caches KDE, GTK, Mesa, icônes…
mesa_shader_cache/Cache GPU OpenGL
*.kcacheCache icônes KDE
__pycache__/Bytecode Python compilé
*.pyc, *.pyoFichiers Python compilés
.DS_StoreMétadonnées macOS si tu travailles aussi sur Mac
terminal · créer ou compléter .gitignore 
$ cat >> .gitignore << 'EOF'

# Cache système (ne jamais committer)
$~
~
.cache/
mesa_shader_cache/
*.kcache

# Python
__pycache__/
*.pyc
*.pyo

# OS
.DS_Store
Thumbs.db
EOF

$ git add .gitignore
$ git commit -m "gitignore: exclure fichiers cache système et Python"
$ git push origin main
✓
